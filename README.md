# THAT WEBSITE'S FUCKED

An independent, responsible investigation into a suspicious Fortnite tournament invitation and a website that appeared to impersonate Fortnite's competitive esports presence.

**Case:** ELARUMI-EPIC-2026-001
**Investigation date:** 22 November 2026
**Prepared by:** Elarumi

Read the full investigation: [THAT-WEBSITES-FUCKED.md](THAT-WEBSITES-FUCKED.md)

## Important

This is a report of suspected phishing and possible brand impersonation. It is not proof of credential theft, the identity of a website operator, or an affiliation with Epic Games.

The domain is deliberately defanged in this repository to reduce the risk of accidental visits.

No credentials were submitted. No unauthorised access, exploitation, or disruption was performed.

## Additional technical finding

Investigator-supplied captures show a Django debug error response exposing application settings and internal implementation details. The report documents this as a potential information disclosure and security misconfiguration, not proof of credential theft or successful exploitation.

## Responsible disclosure

This repository documents observations and reporting attempts. It does not publish private correspondence, account identifiers, screenshots supplied by another person, or the original evidence archive.
